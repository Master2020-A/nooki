Propiedad, préstamos y modelo de memoria

Nooki gestiona la memoria con seguridad comprobada en tiempo de compilación y sin recolector de basura. Esta página describe el modelo: quién es dueño de un valor en el montón, qué pasa al asignarlo o pasarlo como argumento, cómo se presta para leer y para escribir, y qué diagnósticos (NOK5xxx) avisan cuando algo se rompe.

Un solo dueño

Todo valor tiene un dueño en cada momento. Los tipos que guardan memoria en el montón —Caja<T>, texto, Vector<T> y Mapa<K, V>— se transfieren o se prestan de forma explícita, para que no haya ni dobles liberaciones ni fugas.

Caja<T> envuelve un dato en el montón. Se crea con Caja.nuevo(...) y su memoria queda atada al ámbito de la variable dueña: cuando el ámbito termina, el compilador emite la liberación.

Movimiento

La regla es una sola, y es la del ADR-020: pasar un valor con dueño a un parámetro que no es un préstamo lo mueve. Después del movimiento, la variable de origen queda invalidada y usarla es un error de compilación (NOK5001), no un fallo al ejecutar.

funcion consumir(texto_entrante: texto) -> entero {
    retornar texto_entrante.largo()
}

funcion principal() -> entero {
    variable c = "adios" + ""
    variable largo = consumir(c)   // c se mueve aquí
    retornar 0
}

Esa regla es la que evita el doble dueño: si dos variables apuntaran a la misma memoria y las dos la liberaran, el programa se rompería, y el compilador no lo deja escribir.

Prestar: & y &mutable

Para dar acceso sin transferir la propiedad, se presta:

  • &T: préstamo inmutable, solo lectura. Pueden convivir varios a la vez.
  • &mutable T: préstamo mutable, permite escribir a través de la referencia con *p. Solo puede haber uno a la vez, y mientras exista no puede haber ningún otro préstamo al mismo dato.
funcion sumar_a(p: &mutable Caja<entero>, cuanto: entero) -> vacio {
    *p = *p + cuanto
}

El verificador lleva la cuenta de los préstamos activos por ámbito, con su tipo y si son mutables, y rechaza el programa cuando el préstamo escapa de donde vive el dato o cuando se pide uno mutable habiendo otro.

Los diagnósticos de esta parte

Los avisos de propiedad y préstamos son la serie NOK5xxx: uso tras mover (NOK5001), préstamo guardado (NOK5002), préstamo mutable que no es exclusivo (NOK5003), copia de un compuesto con dueño (NOK5004) y préstamo que escapa (NOK5006). Cada uno tiene su caso de conformidad, de modo que el comportamiento está fijado por una prueba y no por la costumbre.

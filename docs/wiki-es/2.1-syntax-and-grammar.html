Sintaxis y gramática

Esta página describe el modelo léxico normativo, las palabras reservadas, la gramática en EBNF (spec/gramatica.ebnf), la precedencia de operadores, las sentencias y expresiones, y las herramientas que comprueban que la gramática no se desvía entre el compilador y los editores.

El modelo léxico y las palabras reservadas

Codificación e identificadores

  • UTF-8: el fuente tiene que ser UTF-8. La marca de orden de bytes (BOM) se ignora y los finales de línea (\n, \r\n, \r) se normalizan a \n.
  • Identificadores: admiten letras acentuadas y tildes (á, é, ñ) y se normalizan a la forma C de Unicode (NFC) antes de compararse, para que dos formas equivalentes sean el mismo nombre (ADR-008).
  • Palabras reservadas: el lenguaje reserva sus palabras y sus tipos primitivos, y ninguna lleva tilde. Escribir función con tilde no es un error silencioso: el compilador lo detecta y sugiere la forma correcta.

Literales y terminación

Las sentencias se separan por saltos de línea, no por punto y coma. Los literales de texto admiten secuencias de escape (\n, \t, \\, \") que el compilador traduce de verdad al carácter correspondiente.

Precedencia de operadores

De menor a mayor precedencia:

  • asignación (=, +=, -=…);
  • o lógico (||);
  • y lógico (&&);
  • igualdad (==, !=);
  • comparación (<, >, <=, >=);
  • rangos (.., ..=);
  • suma y resta (+, -);
  • producto, división y resto (*, /, %);
  • unarios (-, !, &, *, como);
  • postfijos (llamada, índice, ., ?).

Sentencias y expresiones

Nooki es un lenguaje de expresiones: un bloque vale lo que vale su última expresión, salvo que se salga antes con retornar.

  • Control de flujo: si, sino —y sino si encadenado—, mientras, para y coincide para el emparejamiento de patrones.
  • Propagación de errores: el operador postfijo ? sobre resultado<T, E> y opcional<T>.

Herramientas de verificación de la gramática

Para que el analizador del compilador, la gramática de TextMate para VS Code y el paquete de JetBrains no se separen, hay dos guiones en Python:

  • herramientas/generar-gramaticas.py: genera las definiciones de sintaxis de VS Code (JSON) y el paquete de JetBrains (XML plist) desde una sola estructura de datos.
  • herramientas/verificar-gramatica.py: comprueba que las expresiones regulares compilan, que las reglas coinciden entre los paquetes de los editores y que cada token cae donde debe sobre casos concretos.

## 1. 🌅 VISIÓN GENERAL Y FILOSOFÍA

### Nombre: **AURORA**
> *"La luz que precede al amanecer del código en español"*

### Principios Fundamentales

```
┌─────────────────────────────────────────────────────┐
│                  AURORA - PILARES                    │
├─────────────────────────────────────────────────────┤
│ 🔧 Poder de C/C++     → Control total del hardware │
│ 🛡️ Seguridad de Rust  → Memoria segura sin GC      │
│ 🐍 Facilidad de Python → Sintaxis limpia y clara   │
│ 🇪🇸 100% en Español    → Democratización total      │
│ ⚡ Compilado           → Rendimiento nativo         │
│ 🖥️ Multiplataforma    → Windows, Mac, Linux        │
└─────────────────────────────────────────────────────┘
```

### Ejemplo de cómo se vería el código Aurora

```
// Esto es un ejemplo conceptual de Aurora

importar sistema.io
importar ia.redes_neuronales

clase Animal {
    protegido nombre: Texto
    protegido edad: Entero

    constructor(nombre: Texto, edad: Entero) {
        este.nombre = nombre
        este.edad = edad
    }

    publico funcion hablar() -> Texto {
        retornar "..."
    }
}

clase Perro hereda Animal {
    privado raza: Texto

    constructor(nombre: Texto, edad: Entero, raza: Texto) {
        super(nombre, edad)
        este.raza = raza
    }

    publico funcion hablar() -> Texto {
        retornar "¡Guau!"
    }
}

funcion principal() {
    variable mi_perro = nuevo Perro("Rex", 5, "Pastor Alemán")
    imprimir("Mi perro dice: {mi_perro.hablar()}")

    // Manejo de memoria seguro (estilo Rust)
    variable datos: propio Vec<Entero> = nuevo Vec<Entero>()
    datos.agregar(1)
    datos.agregar(2)

    // Préstamo inmutable
    variable referencia: &Vec<Entero> = &datos
    imprimir("Datos: {referencia}")

    // Puntero directo (bloque inseguro para hardware)
    inseguro {
        variable ptr: *Entero = asignar_memoria(4)
        *ptr = 42
        liberar_memoria(ptr)
    }
}
```

## 2. 🏗️ ARQUITECTURA DEL COMPILADOR

### Pipeline Completo de Compilación

```
                    ARQUITECTURA DEL COMPILADOR AURORA
                    ===================================

 Código Fuente (.aur)
        │
        ▼
┌──────────────────┐
│  FASE 1: LÉXICO  │  → Análisis léxico (Tokenización)
│    (Lexer)       │  → Tokens en español
│                  │  → Manejo de UTF-8/Unicode
└────────┬─────────┘
         │ Flujo de Tokens
         ▼
┌──────────────────┐
│ FASE 2: SINTAXIS │  → Parser descendente recursivo
│   (Parser)       │  → Gramática LL(k) / Pratt Parser
│                  │  → Genera AST
└────────┬─────────┘
         │ AST (Árbol Sintáctico Abstracto)
         ▼
┌──────────────────┐
│ FASE 3: SEMÁNTIC │  → Resolución de nombres
│  (Analizador     │  → Verificación de tipos
│   Semántico)     │  → Verificación de propiedad (ownership)
│                  │  → Verificación de préstamos (borrowing)
│                  │  → Verificación de tiempos de vida
└────────┬─────────┘
         │ AST Anotado + Tabla de Símbolos
         ▼
┌──────────────────┐
│ FASE 4: HIR      │  → Representación Intermedia Alta
│ (High-Level IR)  │  → Desugaring
│                  │  → Resolución de genéricos
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ FASE 5: MIR      │  → Representación Intermedia Media
│ (Mid-Level IR)   │  → Verificación de ownership aquí
│                  │  → Análisis de flujo de control
│                  │  → Optimizaciones de alto nivel
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ FASE 6: LIR/     │  → Generación a LLVM IR
│ LLVM IR          │  → O generación directa a ensamblador
│                  │  → Optimizaciones de bajo nivel
└────────┬─────────┘
         │
         ▼
┌──────────────────────────────────────────┐
│         FASE 7: BACKEND                  │
├──────────────┬───────────┬───────────────┤
│   Windows    │   Linux   │    macOS      │
│   (PE/COFF)  │   (ELF)  │  (Mach-O)    │
│   x86_64     │  x86_64  │  x86_64      │
│   ARM64      │  ARM64   │  ARM64 (M1+) │
└──────────────┴───────────┴───────────────┘
         │
         ▼
   Ejecutable Nativo / Biblioteca
```

### 2.2 Módulo Parser

```
COMPONENTES DEL PARSER
======================

Archivo: src/parser/

├── parser.cpp              → Parser principal (Pratt Parser)
├── ast.hpp                 → Definición de nodos AST
├── nodos/
│   ├── expresiones.hpp     → Nodos de expresión
│   ├── declaraciones.hpp   → Nodos de declaración
│   ├── sentencias.hpp      → Nodos de sentencia
│   ├── tipos.hpp           → Nodos de tipo
│   ├── patrones.hpp        → Pattern matching
│   └── modulos.hpp         → Sistema de módulos
├── precedencia.hpp         → Tabla de precedencia
├── gramatica.hpp           → Reglas gramaticales
└── errores_sintacticos.cpp → Errores en español

GRAMÁTICA (BNF simplificada):
══════════════════════════════

<programa>     ::= <declaracion>*
<declaracion>  ::= <dec_funcion> | <dec_clase> | <dec_variable>
                 | <dec_importar> | <dec_modulo> | <dec_interfaz>
                 | <dec_enumeracion> | <dec_estructura>

<dec_funcion>  ::= "funcion" <identificador> "(" <parametros>? ")"
                   ("->" <tipo>)? <bloque>

<dec_clase>    ::= "clase" <identificador> 
                   ("hereda" <tipo>)?
                   ("implementa" <tipo> ("," <tipo>)*)?
                   "{" <miembro_clase>* "}"

<dec_variable> ::= ("variable" | "constante") <identificador>
                   (":" <tipo>)? "=" <expresion>

<sentencia>    ::= <si_sentencia> | <mientras_sentencia>
                 | <para_sentencia> | <coincide_sentencia>
                 | <retornar_sentencia> | <expresion> ";"

<si_sentencia> ::= "si" "(" <expresion> ")" <bloque>
                   ("sinosi" "(" <expresion> ")" <bloque>)*
                   ("sino" <bloque>)?
```

├── verificador_rasgos.cpp      → Verificación de traits/rasgos
└── errores_semanticos.cpp      → Errores descriptivos en español

SISTEMA DE PROPIEDAD (Ownership):
═════════════════════════════════

Reglas fundamentales (adaptadas de Rust):
1. Cada valor tiene exactamente UN propietario
2. Solo puede haber un propietario a la vez
3. Cuando el propietario sale del ámbito, el valor se libera

Préstamos (Borrowing):
- &variable      → Préstamo inmutable (múltiples permitidos)
- &mut variable  → Préstamo mutable (solo uno a la vez)
- propio variable → Transferencia de propiedad (move)

Ejemplo en Aurora:
─────────────────
funcion principal() {
    variable texto: propio Texto = "Hola Aurora"
    
    // Préstamo inmutable
    variable ref1: &Texto = &texto
    variable ref2: &Texto = &texto  // OK: múltiples inmutables
    
    // Préstamo mutable
    variable ref_mut: &mut Texto = &mut texto
    // variable ref3: &Texto = &texto  // ERROR: no se puede
    
    // Transferencia de propiedad
    variable nuevo_dueño: propio Texto = mover(texto)
    // imprimir(texto)  // ERROR: texto ya fue movido
}
```

PIPELINE DE IR:
═══════════════

AST → HIR (desugaring) → MIR (ownership check) → LLVM IR → Nativo

HIR Transformaciones:
- for azucarado → while
- pattern matching → if/switch
- closures → structs + función
- operador ?  → match Result
- string interpolation → concatenación

MIR Características:
- Grafo de flujo de control (CFG)
- SSA (Static Single Assignment)
- Puntos de drop insertados
- Verificación de ownership completa

## 3. 📝 ESPECIFICACIÓN COMPLETA DEL LENGUAJE

### 3.1 Estructura de un Programa

```
ESTRUCTURA BÁSICA DE UN PROGRAMA AURORA
========================================

// Declaración de módulo (opcional)
modulo mi_aplicacion

// Importaciones
importar sistema.io
importar sistema.colecciones.Lista
importar matematicas.{seno, coseno, PI}
importar mi_paquete.utilidades como util

// Constantes globales
constante VERSION: Texto = "1.0.0"
constante MAX_ELEMENTOS: Entero = 1000

// Función principal (punto de entrada)
funcion principal() {
    imprimir("¡Hola, Aurora!")
}

// O con argumentos
funcion principal(argumentos: Vec<Texto>) -> Entero {
    imprimir("Argumentos: {argumentos}")
    retornar 0
}
```

### 3.2 Variables y Constantes

```
VARIABLES Y CONSTANTES
=======================

// Variables mutables
variable nombre: Texto = "Aurora"
variable edad: Entero = 25
variable precio: Flotante64 = 19.99
variable activo: Booleano = verdadero

// Inferencia de tipos
variable mensaje = "Hola"          // Texto inferido
variable contador = 0              // Entero inferido
variable temperatura = 36.5        // Flotante64 inferido

// Constantes (inmutables)
constante PI: Flotante64 = 3.14159265358979
constante NOMBRE_APP: Texto = "Aurora"

// Variables mutables explícitas
variable mut lista = nueva Lista<Entero>()

// Tipo opcional (nullable seguro)

// Destructuring
variable (x, y, z) = obtener_coordenadas()
variable {nombre, edad} = obtener_persona()
```

### 3.3 Estructuras de Control

```
ESTRUCTURAS DE CONTROL
======================

// Condicional
si (edad >= 18) {
    imprimir("Mayor de edad")
} sinosi (edad >= 13) {
    imprimir("Adolescente")  
} sino {
    imprimir("Menor de edad")
}

// Expresión condicional (ternario)
variable estado = si (activo) "Activo" sino "Inactivo"

// Bucle mientras
mientras (condicion) {
    // código
    si (emergencia) romper
    si (saltar) continuar
}

// Bucle hacer-mientras
hacer {
    // código
} mientras (condicion)

// Bucle para (for-each)
para (elemento en coleccion) {
    imprimir(elemento)
}

// Bucle para con rango
para (i en 0..10) {
    imprimir(i)  // 0, 1, 2, ..., 9
}

para (i en 0..=10) {
    imprimir(i)  // 0, 1, 2, ..., 10
}

// Para con paso
para (i en 0..100 paso 5) {
    imprimir(i)  // 0, 5, 10, 15, ...
}

// Bucle infinito
bucle {
    si (condicion) romper
}

// Pattern Matching
coincide (valor) {
    caso 1 => imprimir("Uno")
    caso 2 | 3 => imprimir("Dos o tres")
    caso n si n > 10 => imprimir("Mayor que 10: {n}")
    caso _ => imprimir("Otro valor")
}

// Pattern matching con tipos
coincide (figura) {
    caso c: Circulo => imprimir("Área: {PI * c.radio ** 2}")
    caso r: Rectangulo => imprimir("Área: {r.ancho * r.alto}")
    caso _ => imprimir("Figura desconocida")
}

// Manejo de errores
intentar {
    variable archivo = abrir_archivo("datos.txt")
    variable contenido = archivo.leer_todo()
} atrapar (error: ErrorArchivo) {
    imprimir("Error de archivo: {error.mensaje}")
} atrapar (error: ErrorGeneral) {
    imprimir("Error general: {error.mensaje}")
} finalmente {
    imprimir("Limpieza completada")
}

// Operador de propagación de error
funcion leer_datos() -> Resultado<Texto, Error> {
    variable archivo = abrir_archivo("datos.txt")?
    variable contenido = archivo.leer_todo()?
    retornar Ok(contenido)
}
```

### 3.4 Funciones

```
FUNCIONES
=========

// Función básica
funcion saludar() {
    imprimir("¡Hola!")
}

// Con parámetros y retorno
funcion sumar(a: Entero, b: Entero) -> Entero {
    retornar a + b
}

// Retorno implícito (última expresión)
funcion multiplicar(a: Entero, b: Entero) -> Entero {
    a * b
}

// Parámetros por defecto
funcion crear_usuario(nombre: Texto, edad: Entero = 0, 
                       activo: Booleano = verdadero) -> Usuario {
    retornar nuevo Usuario(nombre, edad, activo)
}

// Parámetros nombrados en llamada
variable user = crear_usuario(nombre: "Ana", edad: 25)

// Funciones genéricas
funcion maximo<T: Comparable>(a: T, b: T) -> T {
    si (a > b) a sino b
}

// Funciones con múltiples retornos
funcion dividir(a: Entero, b: Entero) -> (Entero, Entero) {
    retornar (a / b, a % b)
}

// Funciones lambda/anónimas
variable cuadrado = |x: Entero| -> Entero { x * x }
variable doble = |x| x * 2  // Tipos inferidos

// Funciones de orden superior
funcion aplicar(lista: Lista<Entero>, 
                transformar: funcion(Entero) -> Entero) -> Lista<Entero> {
    retornar lista.mapear(transformar)
}

// Funciones asíncronas
asincrono funcion obtener_datos(url: Texto) -> Resultado<Texto, Error> {
    variable respuesta = esperar http.obtener(url)
    retornar respuesta.cuerpo()
}

// Closures
funcion crear_contador() -> funcion() -> Entero {
    variable mut cuenta = 0
    retornar || {
        cuenta += 1
        cuenta
    }
}

// Sobrecarga de funciones
funcion area(radio: Flotante) -> Flotante {
    retornar PI * radio * radio
}

funcion area(ancho: Flotante, alto: Flotante) -> Flotante {
    retornar ancho * alto
}

// Operadores como funciones
operador +(a: Vector3D, b: Vector3D) -> Vector3D {
    retornar nuevo Vector3D(a.x + b.x, a.y + b.y, a.z + b.z)
}
```

```

==========================

─────────────────

Entero64        → i64   (-2^63 a 2^63-1)
Entero128       → i128

EnteroSinSigno  → u64 (por defecto)
ESS8            → u8    (0 a 255)
ESS16           → u16   (0 a 65,535)
ESS32           → u32   (0 a 2^32-1)
ESS64           → u64   (0 a 2^64-1)
ESS128          → u128

Flotante        → f64 (por defecto)
Flotante32      → f32
Flotante64      → f64

Booleano        → bool (verdadero / falso)
Caracter        → char (Unicode, 4 bytes)
Texto           → String (UTF-8, heap-allocated)
TextoRef        → &str (referencia a texto)
Byte            → u8
Tamaño          → usize
TamañoSignado   → isize
Vacio           → void / unit ()
Nulo            → null (solo para Opcional<T>)

TIPOS COMPUESTOS
────────────────
Tupla           → (Entero, Texto, Booleano)
Arreglo         → [Entero; 10]  (tamaño fijo)
Vector          → Vec<Entero>   (tamaño dinámico)
Mapa            → Mapa<Texto, Entero>
Conjunto        → Conjunto<Texto>
Lista           → Lista<Entero> (lista enlazada)
Cola            → Cola<Entero>
Pila            → Pila<Entero>

TIPOS ESPECIALES
────────────────
Opcional<T>     → Some(valor) o Nulo

Referencia<T>   → &T (préstamo inmutable)
ReferenciaMut<T>→ &mut T (préstamo mutable)
Puntero<T>      → *T (puntero crudo, solo en inseguro)
Caja<T>         → Caja<T> (heap allocation, como Box<T>)
Rc<T>           → ContadorRef<T> (reference counting)
Arc<T>          → ContadorRefAtomico<T> (thread-safe RC)
Debil<T>        → RefDebil<T> (weak reference)

TIPOS FUNCIÓN
─────────────
funcion(Entero) -> Entero
funcion(Texto, Entero) -> Booleano
funcion() -> Vacio

CONVERSIÓN DE TIPOS
───────────────────
variable x: Entero32 = 42
variable y: Entero64 = x.como<Entero64>()     // Conversión segura
variable z: Entero8 = x.intentar_como<Entero8>()? // Puede fallar
variable w: Entero8 = x.forzar_como<Entero8>()    // inseguro

SISTEMA DE INFERENCIA
─────────────────────
variable a = 42           // Entero (i64)
variable b = 3.14         // Flotante (f64)
variable c = "hola"       // Texto
variable d = verdadero    // Booleano
variable e = [1, 2, 3]    // Vec<Entero>
variable f = {"a": 1}     // Mapa<Texto, Entero>
```

## 5. 🛡️ SISTEMA DE MEMORIA (Modelo de Seguridad)

```
SISTEMA DE MEMORIA AURORA
==========================

INSPIRADO EN RUST, ADAPTADO AL ESPAÑOL

╔══════════════════════════════════════════════════════╗
║              TRES NIVELES DE MEMORIA                 ║
╠══════════════════════════════════════════════════════╣
║                                                      ║
║  NIVEL 1: SEGURO (por defecto)                      ║
║  ─────────────────────────────                      ║
║  • Ownership automático                              ║
║  • Borrow checker en compilación                     ║
║  • No hay punteros crudos                           ║
║  • No hay fugas de memoria                          ║
║  • No hay data races                                ║
║  • RAII automático (liberación al salir del ámbito) ║
║                                                      ║
║  NIVEL 2: GESTIONADO                                ║
║  ────────────────────                                ║
║  • ContadorRef<T> para compartir propiedad          ║
║  • ContadorRefAtomico<T> para multihilo             ║
║  • Recolector de ciclos opcional                    ║

### Ejemplo de uso del ecosistema IA:

```
importar aurora_ia.datos.MarcoDatos
importar aurora_ia.redes_neuronales.{Secuencial, capas, optimizadores}
importar aurora_ia.tensor.Tensor

funcion principal() {
    // Cargar datos (estilo Pandas)
    variable datos = MarcoDatos.leer_csv("ventas.csv")
    imprimir(datos.describir())
    
    variable datos_limpios = datos
        .filtrar(|fila| fila["precio"] > 0)
        .agrupar("categoria")
        .sumar()
    
    // Crear red neuronal (estilo PyTorch)
    variable modelo = nuevo Secuencial([
        capas.Densa(784, 256),
        capas.BatchNorm(256),
        capas.relu(),
        capas.Dropout(0.3),
        capas.Densa(256, 128),
        capas.relu(),
        capas.Densa(128, 10),
        capas.softmax()
    ])
    
    // Entrenar
    variable optimizador = optimizadores.Adam(modelo.parametros(), lr: 0.001)
    variable perdida = perdidas.CrossEntropy()
    
    para (epoca en 0..100) {
        para (lote en datos_entrenamiento.lotes(32)) {
            variable prediccion = modelo.adelante(lote.x)
            variable error = perdida(prediccion, lote.y)
            error.retropropagar()
            optimizador.paso()
            optimizador.limpiar_gradientes()
        }
        imprimir("Época {epoca}: pérdida = {error.valor()}")
    }
    
    // Guardar modelo
    modelo.guardar("mi_modelo.aurora_modelo")
}
```

clase MiAplicacion hereda Aplicacion {

    }
